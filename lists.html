Списки

Нумерованный список ― Ordered List

Создается дескриптором <ol>.

  1. Элемент 1;
  2. Элемент 2;
  3. Элемент 3;
  4. Элемент 4;
  5. Элемент 5;

Маркированный список ― Unordered List

Создается дескриптором <ul>.

  • Элемент 1;
  • Элемент 2;
  • Элемент 3;
  • Элемент 4;
  • Элемент 5;

Элементы списка ― ListItems

Как в нумерованном, так и в Маркированном списке элементы создаются дескриптором <li>.

Список определений ― Definitions List

Создается дескриптором <dl>, что означает Description List.
Каждый элемент списка описывается двумя дескрипторами: <dt> ― Desription Term и <dd> ― Desription Details.

Нумерованный список
Каждый элемент такого списка имеет точный порядковый номер;
Маркированный список
Каждый элемент такого списка обозначен какии-то символом;
Список определений
Каждый элемент такого списка вводит понятие и дает ему определение;

Вложенность

Списки можно вкладывать друг в друга как угодно, НО, вкладывать список непосредственно в другой список ЗАПРЕЩЕНО!!! Список можно вкладывать только в элемент другого списка!!!
