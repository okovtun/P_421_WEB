Интерпретируемый Интерпретатор - это программа, которая выполняет другие программы.

Переменные

Переменную можно объявить при помощи ключевого слова var, let либо const.

var
объявляет глобальную переменную, независимо от области видимости, в которой она объявлена;
let
объявляет локальную переменную, такая переменная существует только в той области видимости, в которой она объявлена;
const
объявляет локальную константу;
